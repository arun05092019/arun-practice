# Simple Python Todo List

A lightweight, command-line interface (CLI) Todo List manager written in Python. It saves your tasks locally to a text file so your data persists even after closing the program.

## 🚀 Features
- View existing tasks
- Add new tasks
- Delete tasks by their list number
- Persistent local storage (`tasks.txt`)

## 🛠️ How to Run
1. Make sure you have Python installed.
2. Clone this repository.
3. Run the script using your terminal:
   ```bash
   python todo.py
   ```
